# Sources

Toutes les sources citées dans la collection, réunies ici avec un lien vers l'original. Chaque guide garde par ailleurs son propre chapitre de sources, qui précise ce que chaque référence appuie et signale les affirmations pour lesquelles aucune source précise n'a été trouvée.

**Sur les liens.** Les références institutionnelles pointent vers la page officielle. Pour les travaux de recherche, le lien mène à une recherche sur le titre exact plutôt que vers un identifiant deviné : un DOI erroné renvoie vers un autre article, ce qui est pire qu'une recherche. Quand le DOI est connu et vérifié, c'est lui qui est donné.

## Comment lire une date de vérification

Chaque affirmation chiffrée porte sa date dans le texte. Une donnée sans date est une donnée à revérifier, pas une donnée validée. Le détail par guide est dans [Sources et dates de vérification](<../3 - Transversal/Sources et dates de vérification.md>).
