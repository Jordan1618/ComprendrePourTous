# Sauvegardes de design

Chaque dossier contient une version complète des feuilles de style et du
script du site, telle qu'elle tournait à la date indiquée.

Pour revenir à une version : copier son `style.css` et son `app.js` dans
`assets/`, puis relancer `python build.py`.

| Dossier | Description |
|---|---|
| `2026-08-06-sobre` | Première version maison. Sobre, une seule couleur d'accent (vert-bleu), sans illustrations. |
